# Тестирование и контроль качества

## Автотесты (pytest)

Набор покрывает ядро сервиса — аутентификацию/профиль, все автопроверки и
сводный смоук API по ролям. Тесты используют **изолированную SQLite-БД во
временной папке**, поэтому не затрагивают рабочие данные.

```bash
cd backend
pip install -r requirements.txt
pytest                 # 23 теста
```

Или внутри контейнера:

```bash
docker compose exec backend pytest
```

### Что покрыто
| Файл | Проверяет |
|------|-----------|
| `tests/test_auth.py` | регистрация (роль только `participant`), логин, `/me`, PATCH профиля, смена пароля, RBAC (участник ↔ организатор) |
| `tests/test_doc_checker.py` | разделы по синонимам и ё/е-нормализации, объём, изображения, скоринг (до 15) |
| `tests/test_pptx_checker.py` | подсчёт слайдов и распознавание тем презентации |
| `tests/test_code_checker.py` | структура репозитория (README/зависимости/`.gitignore`), LOC, детекция секретов |
| `tests/test_video_summarize.py` | экстрактивное авто-саммари скринкаста (без ML-зависимостей) |
| `tests/test_api_smoke.py` | отсутствие 5xx на ключевых эндпоинтах по всем трём ролям |

## Статический анализ (flake8)

Конфигурация — `backend/.flake8` (`max-line-length=120`, игнор намеренного
выравнивания присваиваний).

```bash
cd backend
flake8 app seed.py tests        # 0 замечаний
```

## Типобезопасность фронтенда (TypeScript)

Vite/esbuild **не** проверяет типы, поэтому отдельно:

```bash
cd frontend
npx tsc --noEmit                # 0 ошибок
```

## Тестовые данные

`backend/seed.py` идемпотентно загружает демо-данные при старте: кейсы,
команды, критерии, алго-задачи и демо-аккаунты. Пароль у всех — `password`:

- `organizer@judge.ru` — организатор
- `jury1@judge.ru`, `jury2@judge.ru` — жюри
- `participant@judge.ru`, `alice@judge.ru`, … — участники
